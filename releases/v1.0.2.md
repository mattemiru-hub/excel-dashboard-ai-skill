# v1.0.2

Intake-hardening release for `excel-dashboard-ai-skill`.

## Highlights

- adds a standard intake form for the first build on unfamiliar datasets
- forces the AI to ask, wait for answers, and confirm the intake block before building
- adds fail-safe clarification rules so the AI cannot skip intake just because field names look familiar
- makes the QA checklist verify not only workbook quality, but also whether the AI asked the right questions first
- clarifies the capability boundary between "real Excel build" and "just wrote guidance"

## What changed

- `SKILL.md`
  - now requires `references/intake-form-vi.md` before the first build on unfamiliar datasets
  - now requires the AI to wait for answers before building
  - now requires a self-audit that intake was actually asked and answered
- `references/intake-form-vi.md`
  - new standard intake form for raw sheet, objective, audience, date field, actual field, target field, slicers, and rebuild vs polish
- `references/clarification-rules-vi.md`
  - adds fail-safe wording
  - forbids skipping intake because the schema looks familiar
  - requires a short intake confirmation block before build
- `references/prompt-template-vi.md`
  - now encodes the full `inspect -> ask -> choose blueprint -> confirm -> build` flow
- `references/qa-checklist-vi.md`
  - now verifies whether intake and blueprint selection were done correctly
- `references/tooling-contract-vi.md`
  - clarifies when an AI must admit it did not truly build the workbook in Excel
- `agents/openai.yaml`
  - default prompt now explicitly says `Do not build immediately` and `wait for my answers`
- `README.md` and `README_vi.md`
  - now document the intake-hardening behavior and the new public release target

## Recommended use

Use this release when you want:

- lower risk of the AI building the wrong dashboard on an unfamiliar dataset
- clearer intake behavior for non-Excel users
- a stronger guarantee that Power Query + Data Model + DAX + PivotChart architecture is discussed honestly
- cleaner handoff when sharing the repo publicly with users who expect the AI to ask before it builds
